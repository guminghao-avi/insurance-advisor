# 全险种推荐规则

## 一、按人生阶段推荐

### 单身青年（25-35岁）
| 险种 | 推荐 | 预算参考 |
|------|------|---------|
| 医疗险 | 百万医疗（保证续保） | 200-400元/年 |
| 意外险 | 成人综合意外 | 100-350元/年 |
| 寿险 | 定期寿（如有房贷） | 500-1500元/年 |
| **合计** | | **800-2250元/年** |

### 家庭支柱（30-45岁）
| 险种 | 推荐 | 预算参考 |
|------|------|---------|
| 医疗险 | 百万医疗（保证续保） | 300-600元/年 |
| 重疾险 | 单次/多次赔付重疾 | 3000-8000元/年 |
| 意外险 | 成人综合意外 | 150-350元/年 |
| 寿险 | 定期寿（保额=年收入10-20倍） | 500-2000元/年 |
| **合计** | | **4000-11000元/年** |

### 给孩子（0-17岁）
| 险种 | 推荐 | 预算参考 |
|------|------|---------|
| 医疗险 | 少儿百万医疗+小额门诊 | 500-1000元/年 |
| 重疾险 | 少儿重疾险 | 1500-4000元/年 |
| 意外险 | 少儿意外险 | 60-170元/年 |
| **合计** | | **2000-5000元/年** |

### 给父母（50-70岁）
| 险种 | 推荐 | 预算参考 |
|------|------|---------|
| 医疗险 | 百万医疗或防癌医疗 | 500-3000元/年 |
| 意外险 | 老人意外险 | 100-400元/年 |
| **合计** | | **600-3400元/年** |

### 储蓄理财
| 需求 | 推荐 | 说明 |
|------|------|------|
| 教育金 | 增额终身寿/年金 | 10-15年后用钱 |
| 养老金 | 养老年金/增额终身寿 | 退休后领钱 |
| 资产传承 | 终身寿/香港储蓄险 | 财富传给下一代 |

## 二、按健康状况推荐

| 健康状况 | 医疗险 | 重疾险 |
|---------|--------|--------|
| 健康体 | 百万医疗（保证续保） | 达尔文12号/超级玛丽16号 |
| 甲状腺结节 | 尊享e生（支持核保复议）| i无忧3.0（核保宽松）|
| 三高/糖尿病 | 免健告百万医疗/防癌医疗 | 众民保免健告重疾 |
| 乙肝 | 免健告百万医疗 | i无忧3.0/哪吒2号 |
| 已有重疾理赔 | 防癌医疗/惠民保 | 众民保免健告重疾 |

## 三、按预算推荐

| 年预算 | 推荐方案 |
|--------|---------|
| 500元以下 | 惠民保+老人/少儿意外险 |
| 500-2000元 | 百万医疗+意外险 |
| 2000-5000元 | 百万医疗+意外险+定期寿 |
| 5000-10000元 | 百万医疗+重疾险+意外险+定期寿 |
| 10000-30000元 | 中高端医疗+重疾险+意外险+寿险 |
| 30000元以上 | 高端医疗+重疾险+寿险+理财险 |

## 四、重疾险选型规则

| 需求 | 推荐产品 | 理由 |
|------|---------|------|
| 性价比最高 | 达尔文12号 | 赔后轻中症继续赔，性价比之王 |
| 有结节 | 超级玛丽16号 | 三大结节额外赔 |
| 高危职业 | 哪吒2号 | 1-6类职业可投 |
| 大品牌 | 阿基米德2025/i无忧3.0 | 太平洋/人保 |
| 多次赔付 | 守卫者7号 | 不分组赔6次 |
| 非标体兜底 | 众民保免健告重疾 | 无健康告知 |
