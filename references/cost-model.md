# 医疗险年花费计算模型

## 核心公式

年总花费 = 年保费 + 自付免赔额 + 自付比例部分 + 不保项目费用

## 三种使用场景

### 轻度使用（日常门诊）
- 看门诊 1-3 次，拿药若干
- 门诊花费约 500-2000 元
- 百万医疗险：年保费 + 0（门诊不报，百万医疗只报住院）
- 小额医疗险：年保费 + 0（门诊可报）
- 实际影响：主要看门诊险是否覆盖

### 中度使用（住院1次）
- 因病住院，总花费 3-5 万元
- 社保报销后自付约 1-2 万元

计算步骤：
1. 总医疗费：40000 元（取中间值）
2. 社保报销约 60-70%：约 26000 元
3. 自付部分：约 14000 元
4. 百万医疗报销：自付14000 - 免赔额10000 = 4000 元
5. 实际自掏腰包：14000 - 4000 = 10000 元
6. 年总成本 = 年保费 + 10000 元

如果搭配小额医疗险（0免赔）：
1. 小额医疗险报销：自付14000 中的 10000 元（保额内）
2. 百万医疗报销：剩余 4000 中超免赔部分
3. 实际自掏腰包可能降到 0-2000 元
4. 年总成本 = 百万医疗保费 + 小额医疗保费 + 0-2000 元

### 重度使用（大病住院）
- 重大疾病住院，总花费 20-50 万元
- 社保报销后自付约 10-25 万元

计算步骤：
1. 总医疗费：300000 元（取中间值）
2. 社保报销约 50-60%：约 165000 元
3. 自付部分：约 135000 元
4. 百万医疗报销：135000 - 10000（免赔额）= 125000 元
5. 实际自掏腰包：10000 元（仅免赔额）
6. 年总成本 = 年保费 + 10000 元

## 关键对比维度

| 维度 | 说明 |
|------|------|
| 免赔额 | 越低越好，但保费会更高 |
| 报销比例 | 通常 100%（社保内），外购药需看条款 |
| 续保方式 | 保证续保 > 非保证续保（最核心的长期价值） |
| 保额 | 百万医疗通常 200-600万，实际用到上限极少见 |
| 等待期 | 首次投保等待期，30天或90天 |

## 选型决策树

预算 < 300元/年？
  ├─ 健康 → 百万医疗险（保大病）
  └─ 有慢病 → 防癌医疗险（保癌症）

预算 300-800元/年？
  ├─ 给孩子 → 百万医疗 + 小额医疗
  └─ 给成人 → 百万医疗（选保证续保的）

预算 800-3000元/年？
  └─ 想要好体验 → 中端医疗险

预算 8000+元/年？
  └─ 高端医疗险（全球+私立+直付）
