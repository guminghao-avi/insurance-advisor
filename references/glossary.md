# 保险术语表

## 基础术语

| 术语 | 大白话解释 |
|------|-----------|
| 保额 | 保险公司最多赔你多少钱 |
| 保费 | 你每年交给保险公司的钱 |
| 免赔额 | 低于这个金额的自己付，超过的保险公司赔 |
| 等待期 | 买了保险后要等多久才能用（一般30-90天） |
| 犹豫期 | 买了之后反悔可以全额退保的期限（一般15-20天） |
| 保障期间 | 这份保险保你多久（1年/保到70岁/终身） |
| 缴费期间 | 你要交多少年的保费（10年/20年/30年） |
| 投保人 | 出钱买保险的人 |
| 被保险人 | 被保险保障的人 |
| 受益人 | 出事了拿钱的人 |

## 医疗险术语

| 术语 | 大白话解释 |
|------|-----------|
| 百万医疗险 | 保额几百万，但有1万免赔额，主要保大病住院 |
| 小额医疗险 | 保额1-2万，0免赔额，保门诊和小额住院 |
| 防癌医疗险 | 只保癌症的医疗费用，慢病人群可投 |
| 保证续保 | 在约定期间内，即使你理赔过或身体变差，保险公司也必须让你续保 |
| 非保证续保 | 产品停售或你身体变差，可能无法续保 |
| 外购药 | 医院没有、需要去外面药房买的药（通常很贵） |
| 质子重离子 | 一种先进的癌症治疗手段，一个疗程几十万 |
| 特需部/国际部 | 医院里更好的就医环境，不用排队，但费用高 |
| 直付 | 保险公司直接把钱付给医院，你不用先垫钱 |

## 重疾险术语

| 术语 | 大白话解释 |
|------|-----------|
| 重疾险 | 确诊重大疾病直接赔一笔钱（不是报销，是直接给钱） |
| 单次赔付 | 重疾只赔一次，赔完合同结束 |
| 多次赔付 | 重疾可以赔多次（如赔6次） |
| 不分组 | 多次赔付的一种，所有疾病放一起赔，获赔概率更高 |
| 分组 | 多次赔付的一种，疾病分组，同组只能赔一次 |
| 轻症/中症 | 比重疾轻的疾病，赔一部分保额（如30%-60%） |
| 豁免 | 得了轻症/中症后，后面的保费不用交了，保障继续 |

## 寿险术语

| 术语 | 大白话解释 |
|------|-----------|
| 定期寿险 | 保一段时间（如保到60岁），到期没出事保费不退 |
| 终身寿险 | 保一辈子，一定会赔（因为人终有一死） |
| 增额终身寿 | 保额会随时间增长的终身寿，兼具保障和储蓄功能 |
| 现金价值 | 退保能拿回来的钱 |
| IRR | 内部收益率，衡量投资回报的真实利率（考虑复利） |

## 理财险术语

| 术语 | 大白话解释 |
|------|-----------|
| 年金险 | 现在交钱，未来定期领钱（像退休工资） |
| 快返年金 | 交完钱很快就能开始领（如第5年就开始） |
| 养老年金 | 退休后才开始领的年金 |
| 分红型 | 除了保证收益，还有浮动分红（分红不保证） |
| 固收型 | 收益写在合同里，确定不变 |
| 万能账户 | 一个有保底利率的账户，钱放里面会增值 |

## 香港保险术语

| 术语 | 大白话解释 |
|------|-----------|
| 多重危疾 | 重疾可以赔多次 |
| 分红实现率 | 保险公司实际分的红和当初演示的比例（100%说明说到做到） |
| 保费假期 | 暂时不用交保费，保障继续 |
| 保单分拆 | 一张保单拆成多张给不同人 |
| 货币转换 | 保单币种从美元换成人民币等 |
