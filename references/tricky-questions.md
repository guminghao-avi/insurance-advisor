# 刁钻问题应对指南

## 一、产品对比类刁钻问题

**Q：你们推荐的产品是不是收了广告费？**
A：不收任何保险公司的广告费。产品推荐完全基于公开的条款信息、保费数据和行业理赔数据。你可以通过金融监管总局官网核实任何产品的备案信息。推荐逻辑是：先了解你的需求和预算，再从产品库中匹配最适合的，而不是反过来。

**Q：网上说XX产品有坑，是真的吗？**
A：我会帮你逐条分析。常见"坑"其实是消费者误解：
- "不保证续保"→ 非保证续保≠不能续保，只是产品停售时无法续
- "1万免赔额"→ 社保报销后的自付部分才计入，大病住院自付通常超过1万
- "既往症不赔"→ 投保前已有的疾病不赔，投保后新发的正常赔
- "等待期90天"→ 首次投保才等，续保没有等待期

**Q：为什么你们推荐的都是小公司的产品？大公司不靠谱吗？**
A：大公司和小公司在理赔上没有本质区别——所有保险公司都受金融监管总局监管，偿付能力必须达标，理赔都按合同条款执行。所谓"小公司"其实注册资本都在几亿到几十亿。大公司产品通常品牌溢价更高，同等保障下保费可能贵20-40%。

**Q：保险公司的偿付能力低是不是就赔不起？**
A：偿付能力充足率低于100%才会被监管重点关注。即使某公司偿付能力下降，监管会采取限制新业务、增资等措施，消费者的保单权益受《保险法》保护，不会"赔不起"。可以关注但不必过度担忧。

## 二、理赔类刁钻问题

**Q：保险公司会不会故意不赔？**
A：2025年行业平均获赔率约98%，平安人寿获赔率99.2%。拒赔的主要原因是：
1. 未如实告知健康状况（占拒赔原因首位）
2. 不在保障范围内（如意外险不赔疾病）
3. 等待期内出险
4. 免责条款约定的情形

只要如实告知、符合理赔条件，保险公司有法律义务赔付。如果拒赔不合理，可以向银保监投诉或走法律途径。

**Q：买了保险生了病，保险公司说不在保障范围内怎么办？**
A：首先仔细看条款中的"保险责任"和"责任免除"。如果争议较大：
1. 要求保险公司出具书面拒赔理由
2. 向当地银保监局投诉（12378热线）
3. 申请保险行业调解
4. 向法院起诉（保险合同纠纷，法院通常倾向保护消费者）

**Q：网上买保险理赔会不会比线下难？**
A：不会。线上和线下购买的保险，理赔流程和标准完全一样，都按合同条款执行。线上理赔反而更便捷——很多公司支持APP拍照上传材料，AI审核最快8秒出结果。

## 三、产品选择类刁钻问题

**Q：返还型保险是不是比消费型划算？**
A：不一定。返还型看似"不花钱"，但实际：
- 保费比消费型贵2-3倍
- "返还"的钱其实是你多交的保费+很低的利息
- 如果把多交的钱自己理财，收益通常更高
- 适合人群：完全没有储蓄习惯、需要"强制储蓄"的人

**Q：增额终身寿的IRR才2%，银行存款都比它高，为什么要买？**
A：增额终身寿的核心价值不是高收益，而是：
1. **确定性**：收益写在合同里，不受利率下行影响（银行存款利率可能继续降）
2. **复利增长**：2%是复利，长期持有实际收益高于单利2%
3. **锁定利率**：现在买入等于锁定了未来几十年的2%+利率
4. **灵活性**：可以减保取现，相当于一个"会长大的活期账户"

**Q：分红型保险的分红靠谱吗？**
A：分红不保证，这是合同里明确写的。但可以通过以下方式判断：
- 看历史分红实现率（官网可查，100%说明说到做到）
- 保底收益部分是确定的（如1.0-1.3%）
- 分红来自保险公司的可分配盈余，取决于投资收益
- 建议：按保底收益做决策，分红当惊喜

**Q：香港保险真的比内地好吗？**
A：不一定，看具体需求：
- 香港重疾险：多重赔付设计更成熟，但必须赴港签单
- 香港储蓄险：预期收益更高（6-7%），但分红不保证
- 内地保险：购买方便、法律保护更直接、部分产品性价比更高
- 建议：预算充足+有海外配置需求可以考虑香港保险，否则内地产品足够

## 四、行业类刁钻问题

**Q：保险公司会不会倒闭？我的保单怎么办？**
A：保险公司理论上可以破产，但实际极难发生——因为：
1. 保险公司有最低偿付能力要求
2. 监管会提前介入（限制业务、要求增资）
3. 即使破产，保单会由其他保险公司接管
4. 《保险法》第92条规定：经营人寿保险业务的保险公司不得解散

**Q：保险代理人/经纪人说的话能信吗？**
A：区分"口头承诺"和"合同条款"。代理人说的话如果不写进合同，理赔时不认。核心原则：
- 一切以保险合同条款为准
- 健康告知以书面问卷为准
- 免责条款以条款原文为准
- 不确定的，打保险公司官方客服核实

**Q：网上那些"保险测评"可信吗？**
A：大部分测评平台本质上是保险销售渠道（靠佣金盈利），"中立性"有限。建议：
- 交叉对比多个来源
- 以保险合同条款为最终依据
- 关注可验证的数据（理赔率、保费、IRR），而非主观评价
- 不要只看"推荐"，也要看"不适合谁"
