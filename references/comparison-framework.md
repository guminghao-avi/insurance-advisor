# 医疗险产品对比框架

## 对比清单

在推荐前，用以下清单逐项检查：

| 检查项 | 说明 | 权重 |
|--------|------|------|
| 续保方式 | 保证续保几年？期满后怎么处理？ | 极高 |
| 免赔额 | 多少？能否递减？重疾是否0免赔？ | 高 |
| 报销范围 | 社保内还是不限社保？外购药报不报？ | 高 |
| 保额 | 总保额多少？单项限额？ | 中 |
| 等待期 | 30天还是90天？ | 中 |
| 增值服务 | 绿通、质子重离子、术后护理等 | 中低 |
| 品牌 | 大公司理赔体验可能更好 | 低 |

## 续保方式详解（最重要的维度）

**保证续保**（强烈推荐）：
- 保证续保期内（如6年/15年/20年），即使产品停售、你理赔过、健康变差，保险公司都必须让你续
- 保证续保期满后，可能需要重新核保
- 有些产品费率可调（每几年可涨价）

**非保证续保**：
- 产品停售就无法续保
- 健康变差或理赔后可能被拒
- 适合作为补充，不建议作为唯一保障

## 免赔额详解

**1万免赔额**（百万医疗标配）：
- 社保报销后，自付超过1万的部分才赔
- 小病住院自付1-2万，百万医疗基本用不上
- 大病住院自付10-20万，百万医疗能报销大部分

**0免赔额**：
- 社保报销后，剩余部分直接赔
- 保费更高，但小额住院也能赔
- 适合搭配百万医疗使用

## 常见陷阱

- 只看保额不看免赔额 → 600万保额实际用不到
- 只看保费不看续保 → 便宜但停售就没了
- 不看外购药条款 → 大病很多药医院没有，需要外购
- 忽略健康告知 → 理赔时被拒
- 不看等待期 → 刚买就出险不赔
