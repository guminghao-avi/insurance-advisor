# 保险推荐模板

## 标准推荐格式

当用户需要推荐保险时，按以下模板输出：

---

### 你的需求画像

| 维度 | 你的情况 |
|------|---------|
| 给谁买 | [自己/孩子/父母/配偶] |
| 年龄 | [具体年龄] |
| 预算 | [每年X元] |
| 健康状况 | [健康/有XX问题] |
| 核心关注 | [性价比/保障全面/大品牌/...] |
| 已有保障 | [无/已有XX] |

### 推荐方案

| 险种 | 推荐产品 | 年保费 | 保障要点 |
|------|---------|--------|---------|
| 医疗险 | [产品名] | [X元] | [一句话说明] |
| 重疾险 | [产品名] | [X元] | [一句话说明] |
| 意外险 | [产品名] | [X元] | [一句话说明] |
| 寿险 | [产品名] | [X元] | [一句话说明] |
| **合计** | | **X元** | 占年收入X% |

### 每款产品详解

#### 产品名称（保险公司）

**一句话推荐**：[为什么适合你]

**核心信息**
- 保额：XX万
- 保费：XX元/年
- 保障期间：XX
- 免赔额/等待期：XX

**亮点**
- [亮点1]
- [亮点2]
- [亮点3]

**需要注意**
- [注意1]
- [注意2]

**场景化花费**（医疗险适用）
| 场景 | 总费用 | 社保报销 | 保险报销 | 你实际花 |
|------|--------|---------|---------|---------|
| 小病住院 | 2万 | 1.3万 | 0 | 7000元 |
| 大病住院 | 30万 | 16.5万 | 12.5万 | 1万元 |

### 重要提醒

1. **健康告知**：买之前一定要如实告知健康状况
2. **等待期**：首次投保有等待期，期间出险不赔
3. **免责条款**：请仔细阅读免责部分
4. **[其他根据险种的具体提醒]**

| 第20年现金价值 | XX元 | 退保能拿回的钱 |
